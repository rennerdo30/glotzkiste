libmpv in Glotzkiste

Glotzkiste uses libmpv, loaded at runtime as a separate library: the file
libmpv-2.dll next to glotzkiste.exe. It is not part of Glotzkiste's own code.

Replacing it
  Replace libmpv-2.dll next to glotzkiste.exe with any compatible build
  (client API 2.x with the Direct3D 11 render API, x86-64). Glotzkiste loads
  whatever file is there.

What it is
  mpv, commit fe753a7824 (2026-11-13), built as libmpv with its LGPL
  configuration (x86-64-v3, needs AVX2). The DLL contains FFmpeg and other
  libraries built in the same LGPL configuration.

  in LGPL-2.1.txt next to this file.

Source code
  mpv:              https://github.com/mpv-player/mpv/tree/fe753a7824
  The build:        https://github.com/zhongfly/mpv-winbuild/releases/tag/2026-11-13-fe753a7824
  Build scripts and patches for the exact configuration, including FFmpeg and
  every bundled library and its version, are in that repository at that tag.
  If those links stop working, ask for the source at
  https://github.com/rennerdo30/glotzkiste/issues and it will be provided for
  at least three years after this release.
